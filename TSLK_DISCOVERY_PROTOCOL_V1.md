### 1. Fundamental Research Principles
1. **Absolute Methodological Isolation**: Every corpus (001 to 014) is investigated as if it were the sole surviving document of an unknown language. Zero external grammars, dictionaries, machine translation models, or linguistic typologies may be consulted.
2. **Primary Text Sovereignty**: All linguistic regularities must be induced strictly from primary written evidence. No silent editing, normalization, or spelling correction is permitted.
3. **Decoupling of Observation from Interpretation**: Research is strictly partitioned into **Layer A (Blind Discovery Record)** and **Layer B (Interpretive Hypotheses)**.

---

### 2. Layer A: Blind Discovery Record Rules
* **Strict Terminology Ban**: The terms `noun`, `verb`, `subject`, `object`, `predicate`, `linker`, `relator`, `suffix`, `prefix`, `clitic`, `ergative`, `nominative`, `aspect`, `tense`, `mood`, `accepts`, `takes ending` are strictly prohibited in Layer A.
* **Neutral Distributional Classes**: Classes are defined strictly by observable syntactic environments (e.g. `Class D01 = forms displaying surface variants ending in {-a, -ê, -ên} immediately before members of D02`).
* **Morphological Sequences**: Sequences such as `di`, `na`, `bi`, `ne` must be recorded as left-adjacent strings with structural attachment status explicitly marked unresolved.
* **Semantic Neutrality**: Zero unestablished English translations. Unproven meanings are recorded as `SEMANTIC VALUE UNRESOLVED`.

---

### 3. Layer B: Interpretive Hypotheses Rules
* **Evidential Basis**: Every hypothesis must explicitly cite supporting Layer A occurrences.
* **Competing Hypotheses**: At least one competing structural explanation must be formulated.
* **Counterexample Register**: Non-conforming cases must be itemized and analyzed.
* **Decisive Tests**: Must define the empirical criteria (e.g. spoken acoustic stress data) required to decide between competing hypotheses.
* **Cross-Corpus Isolation**: Comparative testing is strictly deferred to the cross-corpus synthesis phase: `[CROSS-CORPUS TEST RESERVED FOR LATER COMPARATIVE PHASE]`.

---

### 4. Non-Circular Mathematical Modeling
* **Non-Circularity Guarantee**: The defining property of a class must never be the variable tested statistically ($	ext{Classification Criterion} 
eq 	ext{Tested Variable}$).
* **Pre-established Rules**: Relevant units, supporting cases, non-conforming cases, ambiguous cases, and exclusions must be operationalized before calculation.
* **Itemized Audit Appendix**: Every analyzed unit must be published in an explicit table with locator, text snippet, observed element, and classification.

### 5. Six-Part Methodological Validation Audit

| Audit Criterion | Core Evaluation Standard | Pass Requirement |
| :--- | :--- | :--- |
| **A. Observation Purity** | Could every Layer A statement have been produced by a researcher with no prior Kurdish knowledge? | Zero conventional grammatical terms in Layer A. |
| **B. Evidential Traceability** | Can every observation, count, hypothesis, and mathematical result be reconstructed from exact locators? | 100% of claims cite exact primary locators. |
| **C. Non-Circularity** | Does any model use the same property both to define a class and to prove something about that class? | Classification criterion distinct from tested variable. |
| **D. Semantic Contamination** | Has any lexical/grammatical meaning entered from pretrained knowledge? | Zero unproven English translations; explicit `SEMANTIC VALUE UNRESOLVED`. |
| **E. Cross-Corpus Contamination** | Has evidence from another corpus been used during independent analysis? | Zero cross-corpus leakage; comparative tests formally deferred. |
| **F. Mathematical Reproducibility** | Can another researcher independently reproduce every numerator, denominator, and percentage? | Complete itemized audit table required for all analyzed units. |
