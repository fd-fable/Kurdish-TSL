# Kurdish-TSL — Sciences of Language V1

This layer extends the project from exhaustive dictionaries and named-source convergence into evidence-bounded structural language science.

## Scope

1. Word-structure profiles
2. Morphological-candidate relations
3. Recurrent structural / grammar-candidate relations
4. Evidence scores (not correctness scores)
5. Literature / register source profiles
6. Language graph construction
7. Final integrated findings and deep conclusion

## Epistemic rule

This layer does not assume familiar Kurdish grammar. Mechanical relations are described first. Conventional labels such as suffix, prefix, tense, case, noun, verb, subject, object, ergative, etc. are not automatically assigned.

A score measures strength of documentary evidence, not linguistic truth.
